## 四、给 DSH 的精准修复方案（3D 高度场 / 着色器管线一行代码级根治）

刚才出现黏连的原因非常明确：原图 `1024×1024` 中，**3 个独立连通部件（左猫 `1`、右猫 `2`、左下尾尖 `3`）之间的最窄留白切缝宽度只有 `9.4px`**。上一轮对整张合并 Alpha 图直接做了大半径高斯模糊，导致相邻部件的模糊边缘在 `9.4px` 缝隙中间叠加超过了 `0.5` 阈值，把原本独立的 **3 个连通域（Connected Components = 3）** 糊成了 **1 个连体块（Connected Components = 1）**。

**只要改成「按连通域拆分独立图层 + 锁定原图 Alpha 剪影」两步，就能 100% 根治黏连且保持表面极致丝滑：**

1. **第一步：先用连通域标记（`scipy.ndimage.label` / `cv2.connectedComponents`）把 `logo-原图透明底参考.png` 的 Alpha 拆成 3 张完全独立的蒙版图层 `M_1, M_2, M_3`**
   - **不要对轮廓做大半径外扩模糊！** 直接保留原图 `logo-原图透明底参考.png` 本身干净平滑的抗锯齿 Alpha（顶多在**各自独立图层 `M_i` 内**做 `sigma = 1.0–1.5px` 且不向外膨胀的微抗锯齿），这样 3 个部件之间的 `9.4px` 切缝和猫耳凹槽 **100% 物理隔离、绝不可能发生任何跨部件粘连**。
2. **第二步：在每个独立部件 `M_i` 内部单独计算「无棱线圆拱高度场」并独立着色，最后再把 3 层合成**
   - 对每个 `M_i` 单独求内部泊松充气高度场 $\nabla^2 h_i = -1$（在 `M_i` 外部固定 $h_i = 0$），再对 $h_i$ 在内部做适度高斯平滑后取圆拱曲线 $H_i = h_i^{0.6}$（这样既消除了欧氏距离场的中轴屋脊棱线，又严格收敛在原图 `M_i` 边界为 0）；
   - 对每个部件单独用 $H_i$ 算法线贴图并渲染左上宽柔棚拍高光 + 清澈冰蓝渐变，最后用原图的精确抗锯齿 Alpha `A_i` 裁切合成——**成品既有刚才那版水滴果冻般的丝滑圆润曲面，轮廓切缝又和原图 100% 像素级严丝合缝，零粘连！**
